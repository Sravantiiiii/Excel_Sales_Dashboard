# Excel Sales Dashboard

An interactive Sales Dashboard created using Microsoft Excel to analyze sales performance and provide clear business insights.

## Project Overview

This project transforms sales data into an interactive dashboard using Excel PivotTables, PivotCharts, KPIs, Slicers, and a Timeline.

The dashboard helps analyze sales performance across different regions, categories, salespersons, payment methods, and order statuses.

## Dashboard Features

- Total Sales KPI
- Total Net Sales KPI
- Total Orders KPI
- Average Discount KPI
- Net Sales by Salesperson
- Net Sales by Region
- Net Sales by Category
- Payment Mode Distribution
- Order Status Analysis
- Interactive Slicers
- Order Date Timeline

## Tools & Excel Features Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- Timeline
- Excel Formulas
- Data Analysis
- Dashboard Design
- KPI Visualization

## Key Insights

The dashboard provides an interactive way to identify:

- Top-performing salespersons
- Best-performing regions
- Sales contribution by category
- Payment method distribution
- Order status distribution
- Overall sales and discount performance
